# Calibre on pi52 — Setup Report

Deployed 2026-07-04 on `192.168.1.52` (Pi, aarch64, Debian 12) via `calibre/docker-compose.yml` + `calibre/install.sh`.

Image: `lscr.io/linuxserver/calibre:latest` (Calibre 9.11.0, arm64). Container name: `calibre`. Data in named volume `calibre_calibre_config` mounted at `/config`.

## Setup tasks done

1. **Compose stack created** (`calibre/docker-compose.yml`)
   - Ports: `8091 → 8080` (KasmVNC desktop UI, http), `8092 → 8181` (desktop UI, https), `8081 → 8081` (content server)
   - Host ports chosen to avoid qbittorrent's 8080 on pi52
   - `PUID/PGID 1000` (pi user), `TZ Europe/Vienna`, `restart: unless-stopped`
2. **Installer written** (`calibre/install.sh`) — idempotent bootstrap, re-runnable
3. **Library created** at `/config/Calibre Library` (metadata.db initialized)
4. **Welcome wizard skipped** — `library_path` set, `welcome_wizard_was_run` flagged; desktop opens straight into the library
5. **Content server configured** — port 8081, authentication on (`server-config.txt`)
6. **Content server auto-start enabled** — `autolaunch_server` in the GUI config; server starts whenever the container (re)starts
7. **Upload user created** — user `calibre` with write access in `server-users.sqlite`; credentials generated by `install.sh`, stored in `calibre/.env` on the pi (gitignored)
8. **Deployed & verified** — desktop UI answers 200, content server identifies as `calibre 9.11.0`, data endpoints return 401 without credentials and pass with them, user is write-enabled, container survives restart
9. **Docs updated** — README container index + secrets table + first-run notes, man page entry; commits `94dcd3e` (feat) and `27f1f2d` (fix: autostart pref lives in `calibre.gui2.config`, not `utils.config.prefs`)

## Access

| What | URL | Login |
|---|---|---|
| Desktop UI (full Calibre in browser) | **https://192.168.1.52:8092** | — |
| Content server (books web app) | http://192.168.1.52:8081 | `calibre` / see `~/dockersource/calibre/.env` on pi52 |

No VNC client needed — the desktop streams to the browser.

> **HTTPS required for the desktop UI.** The streaming stack (Selkies/KasmVNC) refuses plain
> http with *"This application requires a secure connection (HTTPS)"* — the browser APIs it
> uses only work in a secure context. Use port **8092** and accept the self-signed certificate
> warning once. Port 8091 (http) is only useful behind a TLS-terminating reverse proxy.
> The content server on 8081 is Calibre's own web app and works fine over plain http.

## Upload books

- **Content server (easiest):** open http://192.168.1.52:8081, log in, click **Add books** — uploads go straight into the library.
- **Desktop UI:** open the KasmVNC side panel (arrow tab on the left edge) → upload the file, then in Calibre click **Add books** and pick it up from the upload folder.

## Convert books

In the desktop UI (https://192.168.1.52:8092): select a book → **Convert books** → choose output format (EPUB, MOBI, AZW3, PDF, …) → OK. The converted format is added to the same book entry.

## Download books

- **Content server:** open a book → download button next to each available format. Works from any device on the LAN, including e-readers' browsers.
- **Desktop UI:** select book → **Save to disk**, then pull the file out via the KasmVNC side panel's download.

## Maintenance

```bash
# update
cd ~/dockersource/calibre && docker compose pull && docker compose up -d

# logs
docker logs calibre

# change content-server password
docker exec -u abc -e HOME=/config calibre calibre-server \
  --userdb /config/.config/calibre/server-users.sqlite --manage-users
```
